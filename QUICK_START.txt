1. Cloudflare account: https://dash.cloudflare.com/sign-up

2. Install Wrangler:
   npm install -g wrangler

3. Authenticate:
   wrangler login
   (Opens browser for approval)

4. Deploy:
   wrangler publish
   
   ✅ Output:
   Published to: https://nexusflix-vip.YOUR_SUBDOMAIN.workers.dev

1. Open Stremio Desktop/Android

2. Go to: Settings → Community Addons

3. Click: "Install addon from URL"

4. Paste your worker URL:
   https://nexusflix-vip.YOUR_SUBDOMAIN.workers.dev/manifest.json

5. Click Install

6. Configure preferences:
   - Quality: 4K / 1080p / 720p / Auto
   - Source: Direct DDL / Torrent / Debrid / Auto
   - Language: English / Hindi / Multi

7. Click "Add to Stremio"

Problem: "Addon not showing in Stremio"
Solution: 
  1. Check manifest.json is accessible (test in browser)
  2. Ensure CORS headers are present
  3. Reload Stremio completely
  4. Try incognito mode

Problem: "No streams found"
Solution:
  1. TMDB API key is already included (works!)
  2. Check torrent sources are online
  3. Try different catalog/content
  4. Clear browser cache

Problem: "Slow performance"
Solution:
  1. Check Cloudflare Workers analytics
  2. Reduce catalog size to 25 items
  3. Add KV caching for catalogs
  4. Verify network connection
